Units of Study

Order + timing (approx). Pacing may shift based on school events and how quickly we master each topic.

Unit Focus
U1 Integer fluency + number sense (multi-step problems, estimation, reasonableness)
U2 Ratios, rates, and unit pricing (fair comparisons + best deals)
U3 Rational Numbers in Real Life
U4 Linear relationships + algebra (tables → equations → graphs; modeling real situations)
U5 Geometry + measurement (area, surface area, volume, Pythagorean theorem, transformations)
U6 Data + probability for decision-making (analyzing claims, fairness, risk)

How This Course Works

For families: This website is the best place to see what we are doing, what to review, and what to complete after an absence.

  • Daily routine: warm-up → task time → practice → exit check
  • Challenge by Choice: Green / Blue / Black tasks (students can move between levels)
  • Real-world focus: money, measurement, data, and decision-making
  • If you miss class: check the current unit page → open the most recent lesson → complete the practice
