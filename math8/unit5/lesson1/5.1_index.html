Overview

In this lesson, we explore growing patterns and learn how to represent them using tables and equations. We focus on identifying how patterns grow and using that pattern to make predictions.

Learning Targets

  • Describe how a pattern grows
  • Create a table of values from a pattern
  • Write an equation to represent a pattern
  • Use an equation to predict values

Big Idea

Patterns can be described using rules, and those rules allow us to predict any value without continuing the pattern.

Instead of drawing every step, we can use math to jump directly to any figure.

In-Class Work

  • Analyze visual tile patterns
  • Describe how the pattern grows
  • Create tables of values
  • Find the rate of change and starting value
  • Write equations to model the pattern
  • Use equations to solve forward and backward problems

Your Job

  • Look for how the pattern changes each step
  • Keep your table organized
  • Show your thinking clearly
  • Check if your equation matches your table

Helpful Reminder

  • Linear patterns grow by the same amount each time
  • Equation form: Total = (rate × figure #) + starting value
  • The rate is how much the pattern increases each step
  • The starting value is what happens at Figure 0

Success Criteria

  • I can describe how a pattern grows
  • I can build a correct table of values
  • I can write an equation that matches the pattern
  • I can use the equation to find missing values
