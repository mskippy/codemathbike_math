Overview

In this lesson, you will continue working with linear relations by identifying patterns, building tables, and writing rules. This class is mostly a work period, so the focus is on practicing the process carefully and showing clear thinking.

Learning Targets

  • Identify how a linear pattern changes
  • Create a table of values that matches a relationship
  • Write a rule for a linear relation
  • Use a rule to solve simple problems

Big Idea

A linear relation changes by the same amount each time.

We can represent a linear relation using a table and a rule, then use that rule to find missing values or solve problems.

In-Class Work

  • Describe how each pattern changes
  • Make a table of values
  • Write a rule for the relationship
  • Use the rule to answer questions when needed

Your Job

  • Describe the pattern clearly
  • Include 5 values in each table
  • Make sure your table includes 0
  • Write a rule that matches your table
  • Complete your work on another piece of paper

Helpful Reminder

  • Linear relations change by a constant amount
  • Rule form: output (y) = (rate of change)(input (x)) + starting value
  • The rate of change tells how much the pattern increases or decreases each step
  • The starting value is the amount when the input is 0
  • Check that your rule matches the values in your table

Success Criteria

  • I can describe how a linear pattern changes
  • I can build a correct table of values
  • I can write a rule in the form y = mx + b
  • I can use the rule to solve a problem

Practice

Today’s work includes a mix of pattern questions and real-world relationships.

  • Green: Build confidence with patterns, tables, and rules
  • Blue: Use rules to solve real-world problems
  • Black: Find missing information and build rules from clues
