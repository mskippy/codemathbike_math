Overview

In this lesson, we will begin working with linear equations. We will move between equations, tables of values, and graphs to see how they all represent the same relationship. We will also check whether coordinate points are solutions to an equation.

Learning Targets

  • Create a table of values from a linear equation
  • Graph a linear relationship from an equation
  • Write a linear equation from a table of values
  • Write a linear equation from a graph
  • Determine whether a point is a solution to an equation

Big Idea

A linear equation shows a relationship where the change is constant. That same relationship can be shown in different ways: as an equation, in a table of values, and on a graph.

When the relationship is linear, the graph forms a straight line.

In-Class Work

  • Create tables of values from given equations
  • Graph linear equations on a coordinate plane
  • Find equations from tables of values
  • Find equations from graphs
  • Check whether ordered pairs are solutions

Your Job

  • Choose values carefully when making a table
  • Plot points neatly and accurately
  • Look for patterns in how the values change
  • Connect the table, graph, and equation together
  • Show your thinking as you work

Helpful Reminders

  • x is the input and y is the output
  • A table of values gives coordinate points you can graph
  • A linear relationship has a constant rate of change
  • Points on the graph must satisfy the equation
  • To test a solution, substitute the x-value into the equation and check the y-value

Success Criteria

  • I can create a table of values from an equation
  • I can graph points from a table correctly
  • I can recognize a linear pattern in a table
  • I can write an equation that matches a table or graph
  • I can test whether a point is a solution

What We Are Practising

  • Equation → Table → Graph
  • Table → Equation → Graph
  • Graph → Table → Equation
  • Checking whether an ordered pair is a solution

Today is about learning the process and making connections between the different representations.
