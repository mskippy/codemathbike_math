Overview

In this lesson, we will represent linear relationships in multiple ways: with words, a table of values, an equation, and a graph. We will use real-world situations to identify the starting value and rate of change, then graph the relationship to show how the variables are connected.

Learning Targets

  • Describe a linear relationship in words
  • Create a table of values from a real-world situation
  • Write an equation to represent a linear relationship
  • Graph points that form a straight-line relationship

Big Idea

A linear relationship changes at a constant rate. When the values are graphed, the points lie on a straight line.

We can move between words, tables, equations, and graphs to understand and represent the same relationship.

In-Class Work

  • Work through a class example on pizza pricing
  • Identify the input and output variables
  • Find the starting value and rate of change
  • Create tables of values
  • Write equations in linear form
  • Graph the relationships on a coordinate plane

Your Job

  • Decide what each variable represents
  • Look for what stays the same and what changes
  • Keep your table organized
  • Use your table to help graph the points accurately

Helpful Reminder

  • Linear relationships have a constant rate of change
  • Equation form: Total = (rate of change × input) + starting value
  • The starting value is the amount when the input is 0
  • The rate of change tells how much the output increases or decreases each step
  • When graphed, a linear relationship forms a straight line

Success Criteria

  • I can identify the starting value in a relationship
  • I can identify the rate of change
  • I can create a correct table of values
  • I can write an equation that matches the relationship
  • I can graph the points clearly and accurately

Practice Relationships

In class, we will work with relationships like these:

  • An appliance salesperson earns a monthly base pay plus money for each appliance sold
  • A phone plan charges a monthly fee plus an additional cost for data used
  • Two workers are paid in different ways and their earnings can be compared
  • Saving money and spending money can both be represented as linear relationships
