Overview

In this lesson, we learn what it means for two ratios to be equivalent. We’ll start by deciding whether two situations show the same relationship, then we’ll learn a reliable method for writing and checking equivalent ratios.

Learning Targets

  • Identify when ratios are equivalent
  • Write equivalent ratios by scaling up or down
  • Decide whether two ratios are equivalent (and justify your decision)
  • Find a missing value in an equivalent ratio

Key Vocabulary

  • Equivalent ratios — Ratios that represent the same relationship
  • Scale — Multiply or divide both numbers by the same value
  • Relationship — How two quantities compare

Big Idea

Equivalent ratios represent the same relationship, even when the numbers change.

If only one number changes (and the other doesn’t), the relationship changes.

Lesson Flow

Notes & Practice

  • Identifying equivalent ratios (Yes/No + a scaling check)

How to Check Equivalent Ratios

Two ratios are equivalent when you can multiply or divide BOTH numbers by the same value.

  • If both parts scale the same way → equivalent
  • If only one part scales (or they scale differently) → not equivalent

In class, you’ll practice using scaling checks, tables, diagrams, and number lines.

What You Should Be Recording
