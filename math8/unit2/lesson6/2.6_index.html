Overview

In this lesson, we use unit rates to decide which option is the best buy. We’ll practice unit rate language (cost per 1) and learn how to spot deals that look good at first — but don’t actually save money.

Learning Targets

  • Calculate unit rates accurately (value per 1)
  • Use correct unit rate language (e.g., dollars per 100 g, dollars per item)
  • Compare similar items across different stores fairly
  • Justify a “best buy” decision using math

Key Vocabulary

  • Unit rate — A rate with a denominator of 1 (or a consistent “per” amount like per 100 g)
  • Unit price — The cost for one unit (per item, per 100 g, per litre, etc.)
  • Best buy — The option with the better unit rate (usually the lower cost per unit)
  • Fair comparison — Comparing using the same units

Big Idea

Unit rates allow fair and meaningful comparisons — especially when packages, sizes, and “multi-buy” deals make prices hard to compare.

Don’t trust the bold numbers. Trust the math.

Lesson Flow

Warm-Up

  • Quick unit rate review (write the units every time!)
  • Practice using the word per correctly in a sentence

Class Example (Teacher-Led)

  • Chips comparison: multi-buy deal vs single price
  • Choose a consistent unit (per 100 g is usually best)
  • Write a full comparison statement using unit rate language

Independent Practice

  • Students try additional comparisons (with support as needed)
  • Focus: choosing good units and explaining decisions clearly

Wrap-Up

  • What makes a comparison “fair”?
  • Why do stores use “2 for ___” pricing?

How to Solve Best Buy Problems

  1. Identify what is being compared (grams, litres, items, packs)
  2. Make the comparison fair by choosing the same units
  3. Find the unit rate (divide to get “per 1” or per 100 g)
  4. Compare unit rates (lower cost per unit is the better buy)
  5. Write a clear conclusion using units

Most mistakes happen when the units don’t match (or aren’t written).
